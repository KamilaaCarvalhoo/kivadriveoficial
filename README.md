# Kiva Drive

Site institucional em HTML, CSS e JavaScript puro.

## Como rodar
Abra `index.html` no navegador, ou suba para o GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta (`index.html`, `style.css`, `script.js`, `assets/`).
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
4. Aguarde e acesse a URL gerada.

## Estrutura
- `index.html` — marcação da página
- `style.css` — estilos
- `script.js` — menu mobile e scroll suave
- `assets/` — imagens
